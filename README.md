# AF SCLC — Evaluación ULTRA (HTML autónomo)

## Qué es
Herramienta interactiva en **HTML + CSS + JS** (sin login) para evaluación / autoevaluación / coevaluación con:
- Calificación por actor: Auto, Coevaluación, Dirección, Presidencia
- Promedios por criterio y por área
- Puntaje final ponderado (pesos configurables)
- Gráficas (Radar por áreas y barras por actor) **sin librerías externas**
- Exportación/Importación JSON (para conservar evidencias y trazabilidad)
- Modo impresión/PDF

## Cómo usar
1) Abre `index.html` en tu navegador.
2) Completa Datos generales (precargados con ejemplo).
3) Califica criterios por actor.
4) Revisa Resultados (gráficas + KPIs).
5) Completa Observaciones y Plan 30/60/90.
6) Exporta a JSON para respaldo o intercambio.
7) Imprime a PDF para firma.

## Nota institucional
- El bloque “Procesos operativos complementarios” (Área D) inicia con **0%** para evitar introducir criterios no formalizados. Si ya existen protocolos firmados (cierre de mes, supervisión de limpieza, etc.), puedes asignarle peso.
